StudentHub Architecture & Sitemap

Complete visual navigation map and modular breakdown across all user roles and portal components.

👨‍🎓 Student Role Module

Primary Access

Core features available to registered and verified students.

  • Landing Page (index.html)
  • About Portal (about.html)
  • Campus Events (events.html)
  • Academic Calendar (calendar.html)
  • Course Resources (resources.html)
  • Student Registration (register.html)
  • Account Login (login.html)

👩‍🏫 Faculty & Coordinator

Academic Staff

Faculty workflows for curriculum, schedules, and event organization.

  • Event Management: Publish & moderate workshops
  • Resource Sharing: Upload lecture slides & lab manuals
  • Attendance & Roster: View participant registrations
  • Notice Board: Broadcast department announcements
  • Campus Inquiries (contact.html)
  • Interactive Evaluation (form.html)

🛡️ System Administration

Admin Only

Central control panel for site moderation, security, and metrics.

  • Admin Dashboard: Real-time student & event statistics
  • User Moderation: Status toggle (Active / Inactive)
  • Student Management: Full CRUD operations with CSV export
  • Event Poster Moderation: Validate file uploads
  • Audit Logs: Immutable IP-tracked activity trail
  • System Health: DB connection diagnostics
