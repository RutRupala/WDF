Practical 02: WCAG 2.1 AA Audit

WCAG 2.1 AA Accessibility Checklist & Audit

Evaluation criteria and verification evidence demonstrating compliance across all 11 StudentHub pages.

Checklist Item / Criterion WCAG Guideline Implementation Technique Status
Skip to Content Link 2.4.1 Bypass Blocks (Level A) <a href="#main-content" class="skip-link"> provides direct keyboard access to the primary view. Passed
Proper Semantic Landmarks 1.3.1 Info & Relationships (Level A) Native HTML5 header, nav, main, section, article, aside, footer. Passed
Explicit Form Labels 3.3.2 Labels or Instructions (Level A) Every form input has a paired <label for="..."> and aria-required indicators. Passed
Heading Hierarchy 1.3.1 Info & Relationships (Level A) Single <h1> per document followed by non-skipping logical <h2> and <h3> order. Passed
Color Contrast Ratio 1.4.3 Contrast (Minimum Level AA) Text-to-background contrast ratio exceeds 4.5:1 across both light and dark modes. Passed
Keyboard Navigability 2.1.1 Keyboard (Level A) All buttons, links, inputs, and custom toggles receive visible focus rings and activate via Space/Enter. Passed
Breadcrumb Navigation 2.4.8 Location (Level AAA) Implemented with <nav aria-label="Breadcrumb"> and distinct active segment indicators. Passed
